    이때부터 제작 기간 시작
  3. 03

    홈 화면 시안

    실제 웹 링크로 첫 화면 시안을 보내요. 휴대폰·PC로 열어 보고 의견을 주세요.

    승인 후 나머지 개발
  4. 04

    개발·수정

    진행 중인 사이트를 링크로 계속 확인할 수 있어요. 수정은 모아서 한 번에.

    기본 수정 횟수 안에서 반영
  5. 05

    검수·잔금·공개

    아래 체크리스트로 함께 확인하고 잔금을 받은 뒤 의뢰인 계정에 공개해요.

    공개 후 14일 오류 무상 수정

상품별 총 제작 기간

원페이지약 1~2주
포트폴리오 사이트약 2주
동아리·학회·팀 소개 사이트약 2~3주

시작일은 자료·구성·착수금이 모두 확인된 날이에요. 정확한 완료 예정일은 견적서에 적어 드리고, 시안 의견이 늦어지거나 자료가 추가되면 그만큼 늘어나요. 급행 제작은 받지 않아요.

완료 확인 체크리스트

  • 폰·PC 화면에서 글자·사진이 깨지지 않는다

  • 오탈자·잘못된 정보가 없다

모두 확인되면 잔금을 받고, 사이트 공개와 소스 파일 전달로 마무리해요.

계약 기준과 자주 묻는 질문

상담 전에 미리 확인할 수 있게 모두 공개해요. 견적서에도 같은 기준을 적어 드립니다.

계약 기준

수정은 어디까지가 1회인가요?
한 번에 모아서 보내주신 수정 목록이 1회예요. 원페이지·포트폴리오 2회, 팀 사이트 3회가 기본이에요.
  • 수정에 포함: 합의된 구성 안에서 글·사진 교체, 색·글자 크기·배치 조정
  • 새 요청으로 봐요: 페이지·기능 추가, 시안 승인 후 디자인 방향 전체 변경 → 옵션이나 별도 견적
시안은 어떻게 받고, 언제 확정되나요?
홈 화면 시안을 실제 웹 링크로 보내드려요. 휴대폰과 PC로 직접 열어 보고 의견을 주세요. 의견을 반영해 승인하시면 같은 디자인으로 나머지 페이지를 만들어요. 의견이 늦어지면 그만큼 일정이 늘어나고, 승인 후 디자인 방향을 통째로 바꾸는 건 새 요청으로 봐요.
오류와 내용 변경은 어떻게 달라요?
오류: 납품한 구성에서 생긴 화면·링크 오류는 공개 후 14일 동안 무상으로 확인하고 수정해요. 의뢰인의 파일 변경이나 외부 서비스(구글폼 등) 변경으로 생긴 문제는 확인 후 따로 안내해요.
내용 변경(새 글·사진으로 교체 등)은 요청 내용을 확인한 뒤 비용과 일정을 안내해요.
취소·환불 기준이 궁금해요
  • 착수금 입금 후 작업 시작 전 취소: 착수금 전액 환불
  • 시안을 받은 뒤 승인 전 취소: 착수금의 50% 환불
  • 시안 승인 후(개발 중) 취소: 착수금 환불 없음, 잔금 청구 없음
  • 일정이 크게 늦어지거나 연락이 오래 끊기는 경우는 그때의 진행 상황을 기준으로 서로 협의해요
결제 방법과 증빙은요?
계좌이체로 착수금 50%, 완료 확인 후 잔금 50%를 받아요. 카드 결제는 받지 않아요. 동아리 예산 집행용 견적서와 입금 확인 내역은 요청하시면 드려요. 세금계산서·현금영수증은 현재 발급하지 않아요.
사이트와 계정, 코드는 누구 것인가요?
  • 사이트: 의뢰인 계정에 공개하는 것을 기본으로 해요. 어떤 서비스·계정으로 공개할지는 제작 시작 전에 함께 확인해요.
  • 도메인·구글폼: 의뢰인 명의로 만들어요.
  • 코드: 제작된 소스 파일 전체를 넘겨드리고, 이후 다른 사람에게 맡겨도 괜찮아요.
  • 글꼴·사진: 사용 조건을 확인한 무료 글꼴(Pretendard 등)을 써요. 보내주신 사진·로고의 저작권은 제공하신 분 책임이고, 유료 이미지가 필요하면 의뢰인이 구매해요.
  • 작업 사례 공개: 완성된 사이트를 제작 사례로 소개할 수 있어요. 원치 않으면 말씀만 해 주세요.
학생 할인은 어떻게 확인하나요?
학생증 사진이나 재학증명서 캡처를 오픈채팅으로 보내주세요. 학교 이름과 이름만 보이면 되고, 학번·사진·생년월일은 가려도 돼요. 확인용으로만 보고 따로 저장하지 않아요. 동아리·학회·학생 창업팀은 대표자 한 명만 확인해요.

자주 묻는 질문

회원가입·로그인·결제·게시판도 만들어 주나요?
아니요. 서버와 데이터베이스가 필요한 기능은 만들지 않아요. 신청 접수는 구글폼·네이버폼, 결제는 계좌 안내나 외부 결제 링크, 공지는 파일 수정이나 노션·인스타그램 연결로 대신해요. 회원만 볼 수 있는 페이지가 꼭 필요하다면 이 서비스와 맞지 않을 수 있어요. 상담 때 솔직하게 말씀드릴게요.
AI로 만드는 건가요?
네. AI 도구를 활용해 제작하고, 화면 구성·글 배치·디자인 방향은 보내주신 자료에 맞춰 정해요. 공개 전에는 휴대폰과 PC에서 모든 페이지·링크가 제대로 열리는지 직접 확인해요. 그래서 확인할 수 있는 단순한 구조의 소개·포트폴리오 사이트만 받고 있어요.
공개 후에 제가 직접 내용을 바꿀 수 있나요?
소스 파일을 드리니 파일 편집이 익숙하다면 직접 고칠 수 있어요. 다만 직접 편집 방법 안내나 잘못 고친 경우의 복구는 기본 제공 범위가 아니에요. 내용 변경이 필요하면 요청 내용을 확인한 뒤 비용과 일정을 안내해요.
디자인을 전혀 몰라도 괜찮을까요?
괜찮아요. 마음에 드는 사이트 몇 개만 보여주시면 색과 글꼴 방향을 제안하고, 시안 단계에서 실제 화면으로 보면서 결정하시면 돼요.
정말 매달 내는 돈이 없나요?
포트폴리오·동아리 안내처럼 비영리 소개 사이트는 GitHub Pages 같은 무료 호스팅으로 매달 비용 없이 운영할 수 있어요. 다만 무료 호스팅은 판매·영업이 주목적인 사이트에는 쓸 수 없는 경우가 있어서, 사이트 목적에 맞는 공개 방식과 추가 비용 여부를 제작 전에 안내해요. 개인 도메인(연 1~2만 원)이나 외부 서비스 유료 기능을 쓰면 그 비용은 따로 들어요.
검색하면 제 사이트가 나오나요?
사이트 제목·설명·공유 미리보기 같은 기본 설정은 해 드려요. 다만 구글·네이버에 언제 반영될지, 몇 번째에 나올지는 검색 회사가 정해서 보장할 수 없어요. 주로 링크를 직접 공유하는 용도로 생각해 주세요.
마감일이 정해져 있는데 가능할까요?
급행 제작은 받지 않아요. 희망 마감일을 상담 때 가장 먼저 알려주시면, 그 안에 확실히 끝낼 수 있을 때만 일정을 잡아 드려요.
