# 03. 모바일 앱 출시 랜딩 — 수면 앱 "달무렵"

> 제작 순서 3번. 폴더 `app-dalmuryup`. `00-공통-가이드.md` 필독. 1기 금지 목록 준수.

## 1. 컨셉
- 가상의 수면 관리 앱 **달무렵** — 수면 사운드·수면 기록·스마트 알람.
- 목적: 앱·스타트업 런칭 랜딩 시장 견본. "온보딩 흐름을 화면으로 설명하는" 능력 증명.
- 문법: **센터 스티키 목업** — 화면 중앙에 고정된 폰 안에서 앱 화면이 스크롤에 따라 바뀐다.
- 무드: 깊은 밤. 미드나잇+라벤더, 별이 이는 하늘, 몽환적이지만 UI는 또렷하게.

## 2. 디자인 토큰
```css
:root{
  --night:   #0D1024;  /* 배경 */
  --night-2: #171B38;  /* 카드/패널 */
  --lav:     #A78BFA;  /* 라벤더 포인트 */
  --moon:    #F5E9C9;  /* 달빛 크림 — 강조 텍스트/달 */
  --text:    #E9EAF4;
  --dim:     #9AA0BF;
  --ease: cubic-bezier(.32, .72, 0, 1);
}
```
- 제목·본문 모두 **Wanted Sans** (제목 800, 본문 400) — CDN:
  `https://cdn.jsdelivr.net/npm/wanted-sans@1.0.3/packages/wanted-sans/fonts/webfonts/variable/split/WantedSansVariable.min.css`
  (font-family: 'Wanted Sans Variable', 'Wanted Sans'; 로드 실패 폴백 'Noto Sans KR').
- 라운드: 큼(24px) — 앱스러운 부드러움. 단 카드 남발 금지, 패널은 페이지당 한 종류.
- **배경 별하늘**: canvas 파티클(별 120개, 미세 트윙클 + 아주 느린 하강). 달(SVG 원 + 그림자)이
  스크롤 진행에 따라 화면을 천천히 가로지른다(전 페이지 공통, reduced-motion 시 정지).
- 그라디언트·오로라 블롭 금지(1기 클래스와 겹침) — 이 사이트의 빛은 **별과 달뿐**.

## 4. index.html — 홈 (플래그십)

### 플래그십: 센터 스티키 폰 목업 + 스크린 전환
- **폰 목업은 순수 CSS로 그린다** (이미지 아님): 라운드 46px 프레임, 노치(다이나믹 아일랜드),
  측면 버튼, 은은한 라벤더 림 라이트(box-shadow). 폭 300px(모바일 240px).
- **앱 스크린 3개도 HTML/CSS로 코딩한 미니 UI다** (이미지 금지 — 이게 실력 증명):
  1. **사운드 화면**: "오늘 밤, 어떤 소리로 잘까요" + 사운드 카드 3개(비 오는 밤/장작불/새벽 파도,
     각각 재생 버튼과 파형 라인) — 파형은 CSS 막대 12개가 잔잔히 움직임.
  2. **수면 기록 화면**: 지난밤 수면 그래프(SVG 곡선: 얕은잠/깊은잠 영역), 수면 점수 87,
     취침 23:40 → 기상 07:10.
  3. **스마트 알람 화면**: 큰 시계 07:00, "얕은 잠 구간에 깨워드려요" 토글, 요일 선택 칩.
- 구조: 트랙 섹션(높이 320vh) 안에 스티키 컨테이너(100dvh 중앙 정렬).
  폰은 중앙 고정, 좌우에 기능 카피가 스텝별로 교차 등장(스텝1 좌측, 스텝2 우측, 스텝3 좌측).
- 스크린 전환: 스크롤 진행도를 3스텝으로 양자화 → 활성 스크린이 아래에서 슬라이드 업 +
  이전 스크린은 위로 살짝 밀리며 어두워짐(전환 0.5s, --ease). 폰 프레임은 스텝마다
  아주 미세하게 기울기 변경(rotate -3°/0°/3°) — 살아있는 느낌.
- 모바일: 폰을 상단 스티키(60vh), 카피는 폰 아래로 흐름. reduced-motion: 3스텝을
  세로로 나열한 정적 3목업으로 해체.

### 목업 트랙 이후
1. **한 줄 신뢰 지표**: "베타 테스터 2,400명 · 평균 수면 점수 +11" (카운트업 금지 — 정적, 달빛색).
2. **기능 3열 프리뷰** — 아이콘(선 스타일 SVG: 파도/그래프/알람) + 이름 + 한 줄. features.html 링크.
3. **다운로드 유도 엔딩** — CTA 밴드 금지: 밤하늘에 큰 초승달 SVG가 떠 있고 그 아래
   "오늘 밤부터, 잘 자요." + **스토어 버튼 2개** (App Store/Google Play — 상표 로고 이미지 금지,
   텍스트+선 아이콘으로 직접 그린 버튼) — 더미 링크.

## 5. 서브페이지
- **features.html** — 기능 3개를 폰 목업(정적, 소형) + 설명 좌우 교차로. 각 기능에
  "이런 밤에 좋아요" 상황 예시 2줄. 마지막에 개인정보 원칙 1줄(수면 데이터는 기기에만 저장).
- **report.html** — "달무렵이 만드는 주간 수면 리포트" 예시: 주간 수면 시간 막대(SVG),
  평균 취침 시각, 수면 점수 추이 라인, 인사이트 카드 2개("수요일마다 늦게 주무시네요").
  ※ 리포트 사이트(01)와 문법 겹치지 않게: 차트는 스크롤 드로잉 없이 진입 페이드만, 다크 톤.
- **pricing.html** — 무료 vs 달무렵 플러스(월 4,900 / 연 39,000) 2열 비교표.
  연간에 "두 달 무료" 문 배지. 하단 환불 정책 1줄.
- **download.html** — 스토어 버튼 2개 크게 + 설치 3스텝(받기→소리 고르기→머리맡에 두기)
  + FAQ details 6개(배터리? 무음모드? 애플워치? 데이터 백업? 알람 안 울리면? 해지?).

## 7. 주의사항
- 폰 목업과 앱 스크린의 완성도가 이 사이트의 전부다 — 스크린 안 타이포·간격을 실제 앱 수준으로.
- 별 canvas는 별 120개 이하, 프레임당 전체 재그리기 대신 트윙클만 갱신. 탭 비활성 정지.
- 클래스(1기)와 톤이 겹치기 쉬움: 그라디언트 텍스트·벤토·형광펜·말풍선 전부 금지 확인.
- 스토어 로고(사과/구글 상표) 이미지 사용 금지 — 텍스트 버튼으로.
