# 01. 스크롤리텔링 연차 리포트 — "새벽상점 2025 그로스 리포트"

> 제작 순서 1번. 폴더 `report-saebyeok`. `00-공통-가이드.md` 필독. 1기 금지 목록 준수.

## 1. 컨셉
- 가상의 신선식품 새벽배송 스타트업 **"새벽상점"** 의 2025 연차 성장 리포트.
- 목적: 기업 소개·IR·연말 리포트·ESG 페이지 시장(B2B 최고 단가)을 여는 견본.
- 문법: 뉴욕타임즈 스크롤리텔링 — **스크롤하면 차트가 그 자리에서 그려진다.**
- 무드: 정갈한 코퍼레이트 에디토리얼. 신뢰, 숫자, 절제된 자신감.
- 가상 정보: 2021 창업 / 직원 47명 / 서울·경기·인천·부산·대구 서비스 / 연 배송 412만 건.

## 2. 디자인 토큰
```css
:root{
  --paper:   #FCFCFA;  /* 배경 */
  --ink:     #1A1F1C;  /* 본문 */
  --green:   #0E5A3A;  /* 딥 그린 — 브랜드/차트 메인 */
  --green-lt:#DCEDE2;  /* 차트 보조/하이라이트 밴드 */
  --amber:   #E0A61B;  /* 차트 보조 시리즈 (딥그린과 대비) */
  --gray:    #6C7470;  /* 축·캡션 */
  --line:    #E3E5E1;
  --ease: linear;      /* 진행도 직결 — 감속 이징 금지 */
}
```
- 제목: IBM Plex Sans KR 700. 본문: IBM Plex Sans KR 400, line-height 1.9.
- **모든 숫자는 IBM Plex Mono** (`font-variant-numeric: tabular-nums`) — 리포트 인장 같은 룩.
- 섹션 헤딩 문법: 3단 스택 금지 → **목차 번호 체계**: 좌측에 `2.1` 식 모노 번호 + 우측에 제목 한 줄
  (재무 보고서 문법). 상단에 얇은 2px 잉크 라인.
- 컨테이너: 본문 텍스트 640px / 그래픽 스테이지 최대 1280px.

## 4. index.html — 리포트 본편 (플래그십)

### 구성 (스크롤 순서)
1. **커버** — 풀화면 아님(85vh). 종이 리포트 표지처럼: 상단 얇은 더블 라인, 중앙에
   모노 라벨 "ANNUAL GROWTH REPORT", 제목 "2025,\n새벽이 만든 숫자들", 하단에
   `발행 — 새벽상점 · 2026.01` + 표지 이미지(`report-hero.jpg`, 하단 절반).
2. **목차** — 리포트답게 실제 목차 리스트 (1. 요약 ~ 5. 다음 새벽). 각 항목 앵커 링크,
   모노 번호 + 점선 없이 얇은 라인.
3. **§1 요약 — KPI 4종** — 화면 진입 시 카운트업: 연 배송 4,120,000건 / 재구매율 74% /
   누적 고객 380,000명 / 직원 47명. 큰 모노 숫자 + 아래 한 줄 설명.
4. **§2 성장 곡선 (스크롤리텔링 씬 1)** — 월별 주문량 라인 차트.
5. **§3 지역 확장 (씬 2)** — 도시별 버블 차트.
6. **§4 고객 이야기 (씬 3)** — 시간대별 주문 분포 막대 차트 + 재구매 도넛.
7. **§5 다음 새벽** — 2026 계획 3줄 + 마무리.
8. **엔딩** — CTA 밴드 금지 → 리포트 마지막 장 문법: 얇은 더블 라인 + 
   "다음 리포트는 2026년 12월에 발행됩니다." + [뉴스레터 구독하기](구글폼) 텍스트 링크 하나
   + 발행 정보(발행처/문의 메일).

### 플래그십: 스크롤리텔링 구현 (씬 1~3 공통 구조)
```html
<section class="scrolly">
  <div class="scrolly-graphic"><svg>…</svg></div>  <!-- position: sticky; top: 20vh -->
  <div class="scrolly-steps">
    <div class="step" data-step="1">…텍스트…</div>  <!-- 각 스텝 min-height: 90vh -->
    <div class="step" data-step="2">…</div> …
  </div>
</section>
```
- 데스크톱: 그래픽 좌측 55% 스티키, 텍스트 스텝 우측 45%가 흘러 지나감.
  씬 2는 좌우 반전(그래픽 우측). 모바일: 그래픽이 상단 스티키(50vh), 텍스트가 아래로 흐름.
- IntersectionObserver로 활성 스텝 감지(rootMargin `-45% 0px -45%`), 스텝 진입마다
  그래픽 상태 전환. 활성 스텝은 잉크색, 비활성은 40% 흐림.
- **씬 1 (라인 차트)**: SVG path 12개월 주문량 곡선. `stroke-dasharray/dashoffset` 으로
  스텝 진행에 맞춰 구간별로 그려짐. 스텝1: 1~4월(완만) → 스텝2: 5~8월(급성장, 해당 구간
  하이라이트 밴드 + 주석 "부산 진출") → 스텝3: 9~12월 + 최고점 도트 펄스 + 값 라벨.
  축·눈금·단위 필수 (진짜 차트처럼).
- **씬 2 (버블)**: 도시 5개(서울/경기/인천/부산/대구) 원 버블 — 스텝마다 도시가 하나씩
  뿅 나타나며(scale 0→1) 반경 = 주문량 비례. 마지막 스텝에서 2026 예정 도시(대전·광주)가
  점선 원으로 등장.
- **씬 3 (막대+도넛)**: 시간대별 주문 막대(새벽 4~6시 피크 강조 — 막대가 아래서 자람),
  스텝 전환 시 도넛(재구매 74%)이 원호로 그려짐(stroke-dashoffset).
- 모든 차트 값은 HTML `data-` 속성에 두고 JS가 SVG를 생성 — 유지보수 시연 목적.
- reduced-motion: 모든 차트를 최종 상태로 즉시 렌더, 스텝 흐림 효과 제거.

## 5. 서브페이지
- **timeline.html** — 중앙 세로 라인 연혁(2021~2025). 연도는 큰 모노, 항목이 좌우 교차.
  스크롤 진행에 따라 세로 라인이 그린으로 채워짐(진행도 직결).
- **team.html** — 대표 인사(사진 `report-founder.jpg` + 2문단) / 팀 사진 3장 그리드
  / 문화 원칙 4개(번호 목차 문법) / 구성원 통계 미니 차트 1개(직군 분포 가로 막대, 진입 시 자람).
- **press.html** — 언론 보도 리스트(날짜 모노 + 매체명 + 제목, 표 형식) 8건 /
  수상 3건(2023 물류혁신대상 등 가상) 카드 없이 리스트로.
- **contact.html** — 채용 중 직군 3개 리스트 + 지원(구글폼) / 투자·제휴 문의 메일 /
  오시는길(지도 임베드, 성수동 가상 주소).

## 7. 주의사항
- 차트가 이 사이트의 주인공 — 장식용 아이콘·일러스트로 대체 금지, 축/단위/출처 캡션까지 갖출 것.
- 카운트업·차트 드로잉은 씬당 1회. 다시 올려봐도 재생 안 함(리포트는 차분해야 함).
- 그린 위 흰 글자만 허용(연그린 위 흰 글자 금지). 데이터 강조는 앰버 1색만 보조로.
- 스텝 텍스트는 문단당 3~4줄 — 길면 스크롤리텔링 리듬이 죽는다.
