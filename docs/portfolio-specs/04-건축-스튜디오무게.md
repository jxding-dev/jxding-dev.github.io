# 04. 건축·인테리어 스튜디오 — "스튜디오 무게 (STUDIO MUGE)"

> 제작 순서 4번. 폴더 `studio-muge`. `00-공통-가이드.md` 필독. 1기 금지 목록 준수.

## 1. 컨셉
- 가상의 건축·공간 디자인 스튜디오 **무게** — "공간의 무게중심을 설계합니다".
- 목적: 작품이 주인공인 고단가 클라이언트(건축·인테리어·사진·에이전시) 견본.
  어워드 에이전시(awwwards) 문법.
- 문법: **가로 스크롤 인덱스 + 커스텀 커서 + 케이스 스터디**. 도면처럼 건조하고 정확하게.

## 2. 디자인 토큰
```css
:root{
  --concrete: #D9D8D4;  /* 배경 — 콘크리트 */
  --black:    #111110;
  --white:    #F4F3F0;
  --safety:   #E8481C;  /* 세이프티 오렌지 — 도면 마킹용, 극소량 */
  --ease: cubic-bezier(.9, 0, .1, 1);  /* 하드 컷 0.3s */
}
```
- 제목: **Gothic A1 900** (한글, 대형·타이트한 자간 -0.03em) + 라틴 라벨 **Archivo** 600.
- 본문: Noto Sans KR 400. 프로젝트 번호·스펙은 Archivo 대문자 12px letter-spacing .12em.
- 모든 요소 각지게(radius 0). 보더는 1px 블랙 — 도면 괘선처럼 섹션을 **실선으로 구획**
  (여백 구획이 아니라 선 구획 — 1기와 반대 문법).
- 번호 체계: 프로젝트마다 `WRK—001` 형식. 페이지 모서리에 도면 마킹(+, 좌표 라벨) 장식.

## 4. 플래그십 ① — 커스텀 커서 (전 페이지, 데스크톱 전용)
- 기본 커서 숨기고(`cursor: none` — 단, 텍스트 입력·링크 접근성 위해 a/button에는
  실제 포커스 스타일 유지) 12px 블랙 원이 마우스를 **관성으로** 따라옴
  (rAF, `pos += (target - pos) * 0.18`).
- 상태 변형: 프로젝트 이미지 위 → 56px 원 + "보기 ↗" 텍스트 / 링크 위 → 4px 점으로 축소
  / 드래그 가능한 가로 스크롤 영역 위 → "◀ 드래그 ▶".
- `mix-blend-mode: difference` 로 배경 무관하게 보임. 터치 기기·`(pointer: coarse)`에서는
  완전 비활성(기본 커서 복귀). reduced-motion: 관성 제거하고 즉시 추적.

## 5. index.html — 홈 (플래그십 ②: 가로 스크롤)
1. **오프닝** — 풀화면 아님: 상단 절반에 대형 타이포 "공간의\n무게중심" (Gothic A1 900,
   clamp 3.5~9rem), 하단 절반에 `muge-hero.jpg` 와이드. 사이 1px 라인. 우측 상단에
   Archivo 라벨 "ARCHITECTURE & INTERIOR — SEOUL / EST. 2018".
2. **가로 스크롤 셀렉티드 웍스** — 핵심 섹션:
   - 구조: 트랙 섹션(높이 = 100vh × 패널 수) 안 스티키 컨테이너, 세로 스크롤 진행도를
     `translateX` 로 변환해 패널 4개가 옆으로 흐름.
   - 패널 = 프로젝트 1건: 큰 이미지(화면의 70%) + 좌하단에 `WRK—001` 번호 +
     프로젝트명(고딕 대형) + 스펙 한 줄(용도/연면적/연도). 4번째 패널 뒤에
     "전체 프로젝트 →" 엔드 패널.
   - 진행 표시: 하단 1px 라인 위를 세이프티 오렌지 마커가 이동 + `01 / 04` 카운터.
   - 이미지 클릭 → work-detail.html (대표작), 나머지는 works.html.
   - **모바일 대체 문법**: 가로 스크롤 해체 → 세로 풀폭 리스트(이미지+번호+제목).
     reduced-motion도 동일하게 세로 해체.
3. **스튜디오 요약** — 좌측 큰 숫자 3개(준공 27 / 수상 6 / 진행 중 4 — 정적, 카운트업 금지)
   + 우측 소개 2문단. 1px 라인 구획.
4. **엔딩** — CTA 밴드 금지: 풀폭 블랙 섹션에 초대형 타이포 "다음 프로젝트,\n무게와 함께."
   + 이메일 주소 자체가 링크(hello@studiomuge.kr, hover 시 세이프티 오렌지). 버튼 없음.

## 8. 주의사항
- 세이프티 오렌지는 "마킹"에만 (진행 마커·hover·치수선 일부). 면적 채움 금지.
- 가로 스크롤 트랙에서 스크롤 하이재킹 금지 — 세로 스크롤 진행도의 수동 변환만
  (휠 이벤트 가로채기·scroll-behavior 조작 금지).
- 커서 때문에 실제 포커스/클릭 판정이 어긋나면 안 됨 — 커서 요소는 `pointer-events: none`.
- 사진이 주인공: 이미지에 필터·틴트 금지, 오버레이는 hover 시 정보 표시용만.
