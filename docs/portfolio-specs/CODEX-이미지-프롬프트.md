# CODEX 전용 — 2기 이미지 생성 프롬프트 (총 49장)

> ⚠️ 코덱스(이미지 생성 AI) 전용 문서. 오푸스는 읽을 필요 없음.
> 생성 후 표의 파일명 그대로 각 사이트 `images/` 폴더에 넣는다.

사용 규칙 (1기와 동일):
1. 모든 프롬프트 뒤에 공통 접미사: `photorealistic, high-end commercial photography, no text, no letters, no watermark, no logo`
   (단, ②향수의 원료·병 컷은 접미사의 photorealistic 앞에 `studio product photography` 사용)
2. 각 사이트의 스타일 접두사를 앞에 붙여 톤 통일.
3. 비율 지원 시 표기대로, 아니면 근접 비율 생성 후 크롭.
4. **② 향수의 병·원료 컷은 반드시 "on pure black background" — 코드에서 screen 블렌드로 합성함.**
