# 00. 공통 제작 가이드 — 2기 플래그십 (모든 사이트 제작 전 필독)

## 이 프로젝트가 무엇인가
크몽 랜딩페이지 서비스의 **2기 플래그십 포트폴리오** 5개를 만든다.
1기(치과·부동산·대시보드·QR메뉴 + 살롱·카페·클래스·필라테스·펜션)가 "업종 소개형"이었다면,
2기는 **사이트마다 기술적 플래그십 하나가 박힌 쇼케이스**다.
보는 순간 "이건 어떻게 만든 거지?"가 나와야 하고, 고단가 시장(제품 브랜드·B2B·에이전시·행사·앱)을 연다.
모든 사이트는 **100% 한국어** (브랜드 워드마크·장식 라벨의 영문만 허용).

## ⚠️ 최상위 원칙: 1기와 비슷하면 실패다
이 폴더 옆에 이미 완성된 1기 사이트들(salon-noir, cafe-mukdo, class-notion, pilates-oneum,
stay-monthlysea)이 있다. **참고하지 말 것. 열어보지도 말 것.** 2기는 완전히 다른 방향이다.

  블롭 호흡 모핑, 세로쓰기 장식, 드롭캡, 점선 가격 리더, 형광펜 하이라이트, 손글씨 악센트,
  Before/After 슬라이더, 풀스크린 슬라이드쇼 히어로 — 전부 1기 것. 금지.
- **페이지 문법**: `작은 라벨 + 큰 타이틀 + 회색 리드문` 3단 섹션 헤딩 스택 금지.
  `100dvh 히어로 → 균등 카드 그리드 → CTA 밴드` 골격 금지.
  호버 `translateY(-Npx)` 카드 상승 금지.
- 1기와 같은 색 조합(크림+브라운, 블랙+골드, 네이비+바이올렛, 세이지+오트밀, 딥블루+화이트) 금지.

## 2기 사이트 DNA 표 (서로도 달라야 한다)
| | 제목 폰트 | 본문 폰트 | 페이지 문법 | 모션 성격 | 밀도 |
|---|---|---|---|---|---|
| 리포트 | IBM Plex Sans KR 700 | IBM Plex Sans KR / 숫자 IBM Plex Mono | NYT 스크롤리텔링(스티키 그래픽+텍스트 스텝) | 스크롤 진행도에 비례해 그려짐 | 중간 |

| 앱 | Wanted Sans 800 (CDN) | Wanted Sans 400 | 센터 스티키 목업 + 좌우 교차 텍스트 | 부드러운 스텝 전환 + 파티클 | 낮음 |
| 건축 | Gothic A1 900 + 라틴 Archivo | Noto Sans KR | 가로 스크롤 인덱스 + 케이스 스터디 | 하드 컷, 즉각적(0.3s) | 중간 |

앱 `cubic-bezier(.32,.72,0,1)` / 건축 `cubic-bezier(.9,0,.1,1)` 0.3s / 컨퍼런스 `steps()` 혼용+0.15s.

## 기술 규칙 (1기에서 검증된 것 승계)
- 바닐라 HTML/CSS/JS만. 프레임워크·빌드도구·라이브러리 금지. 차트도 SVG 직접 그린다.
- 폰트 로드: Google Fonts + 지정 CDN만
  (Wanted Sans: `https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9` 형식이 아니라
  `https://cdn.jsdelivr.net/npm/wanted-sans@1.0.3/packages/wanted-sans/fonts/webfonts/variable/split/WantedSansVariable.min.css`).
- `<html lang="ko">`, viewport 메타, 페이지별 title/description, `defer` 스크립트.
- 내부 링크 상대경로. 외부 링크 `target="_blank" rel="noopener"` + 더미 URL
  (tel: / https://forms.gle/example / https://pf.kakao.com/_examplech / 스토어는 https://apps.apple.com 루트).
- **`body { overflow-x: clip; }` 를 모든 사이트에 기본 포함** (1기에서 100vw breakout 스크롤바 버그 재발 방지).
- 이미지: 설계서 슬롯 표 파일명 그대로, 래퍼에 aspect-ratio+배경색(이미지 없어도 레이아웃 유지),
  히어로 외 `loading="lazy"`, 의미 있는 한국어 alt.
- 반응형: 360px 가로 스크롤 금지, 브레이크포인트 768/1024, clamp() 유동 타이포,
  `word-break: keep-all`. **가로 스크롤·스티키·커서 등 플래그십 기법은 모바일 대체 문법을
  각 설계서에 명시했으니 그대로 따를 것.**
- 접근성: 대비 AA, `:focus-visible` 유지, 시맨틱 태그, 페이지당 h1 1개,
  모든 인터랙션 키보드 조작 가능, `prefers-reduced-motion` 에서 플래그십 모션은
  "완성된 최종 상태"로 즉시 표시 (빈 화면 금지).
- 스크롤 연동은 rAF 1개로 통합, IO로 뷰포트 밖 계산 정지, transform/opacity만 연속 애니메이션.
- 자동 모션은 hover 일시정지·탭 비활성 정지·사용자 조작 시 중단.
