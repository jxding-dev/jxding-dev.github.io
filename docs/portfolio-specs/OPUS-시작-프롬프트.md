# 오푸스에게 전달할 첫 프롬프트 — 2기 플래그십 (복사해서 사용)

```
크몽 포트폴리오 2기 "플래그십" 사이트 5개를 만들 거야. 1기(salon-noir, cafe-mukdo,
class-notion, pilates-oneum, stay-monthlysea)와는 완전히 다른 방향이어야 해.
설계 문서가 portfolio-specs 폴더에 준비되어 있어. 규칙을 정확히 따라줘.

1. 먼저 portfolio-specs/00-공통-가이드.md 를 처음부터 끝까지 읽어.
   특히 "1기 금지 목록"과 "2기 사이트 DNA 표"는 절대 기준이야.
   기존 1기 사이트 폴더는 열어보지 마 — 참고하는 순간 비슷해진다.

2. 사이트는 반드시 한 번에 하나씩, 이 순서로:
   ① 01-리포트-새벽상점.md → report-saebyeok (스크롤리텔링 데이터 리포트)
   ② 02-향수-온도.md → perfume-ondo (고정 스테이지 시네마)
   ③ 03-앱-달무렵.md → app-dalmuryup (스티키 폰 목업)
   ④ 04-건축-스튜디오무게.md → studio-muge (가로 스크롤 + 커스텀 커서)
   ⑤ 05-컨퍼런스-데브웨이브.md → conf-devwave (키네틱 타이포 전광판)

3. 지금은 1번(새벽상점 리포트)만 작업해. 설계서의 페이지 구성·섹션 순서·디자인 토큰·
   플래그십 구현 방식을 그대로 따르고, 설계서에 없는 기능·섹션을 임의로 추가하지 마.

4. 반드시 지킬 것:
   - 각 사이트의 "플래그십 기술"이 이 사이트의 존재 이유다 — 여기에 공을 가장 많이 들여
   - 모든 텍스트 100% 한국어 (설계서가 허용한 워드마크·라벨 영문만 예외)
   - 바닐라 HTML/CSS/JS만, 라이브러리 금지 (차트도 SVG 직접)
   - 1기 금지 목록(폰트·마퀴·그레인·스탬프·글래스·3단 헤딩 스택·CTA 밴드·카드 호버 상승 등)
     의 요소가 하나라도 들어가면 실패
   - 이미지 파일명은 설계서 슬롯 표 그대로 (이미지는 나중에 별도 생성 — 지금은 없음,
     aspect-ratio + 배경색으로 레이아웃 유지, placeholder 서비스·직접 그린 대체 이미지 금지)
   - body { overflow-x: clip } 기본 포함, 360px 가로 스크롤 금지
   - 플래그십 모션의 모바일 대체 문법과 prefers-reduced-motion 정적 표시를 설계서대로
   - 더미 콘텐츠는 설계서 예시 기반으로 실제 회사처럼 구체적으로
   - 파비콘(이모지 SVG 데이터 URI 가능) + og:title/description 태그 포함

5. 사이트 하나가 끝나면 00-공통-가이드.md 하단 체크리스트를 항목별로 자가 검증하고
   결과를 보고한 뒤, 내 확인을 받고 다음 사이트로 넘어가.

지금 1번 새벽상점 리포트부터 시작해.
```
