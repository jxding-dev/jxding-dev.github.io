# 05. 테크 컨퍼런스 — "SEOUL DEV WAVE 2026"

> 제작 순서 5번(마지막). 폴더 `conf-devwave`. `00-공통-가이드.md` 필독. 1기 금지 목록 준수.

## 1. 컨셉
- 가상의 개발자 컨퍼런스 **SEOUL DEV WAVE 2026** — 2026.10.16(금)~17(토), 성수 에스팩토리(가상).
- 목적: 행사·전시·팝업·페스티벌 시장 견본. "정적 페이지로 이런 에너지가 나온다"의 증거.
- 문법: **포스터 전광판** — 2기 유일의 **과밀 디자인**. 여백 대신 밀도, 정돈 대신 에너지.
  글자가 곧 그래픽이다.

## 2. 디자인 토큰
```css
:root{
  --black: #0C0C0C;
  --lime:  #D8FF3E;   /* 형광 라임 — 면적으로 과감하게 사용 */
  --white: #F5F5F2;
  --bd: 3px;          /* 두꺼운 구획 보더 */
  --ease: cubic-bezier(.2, 0, 0, 1); /* 0.15s 즉각 반응 + 일부 steps() */
}
```
- 헤드라인: **Black Han Sans** (한글 전광판체). 라틴/숫자 대형: Archivo 800 압축 자간.
- 본문: Noto Sans KR 500. 라벨: Archivo 대문자.
- 구획: 3px 블랙 보더의 그리드 셀 — 화면을 신문 전면광고처럼 분할. radius 0.
- 배경 교차: 블랙 섹션 ↔ 라임 섹션 (라임 위 텍스트는 반드시 블랙).
- 장식: 화살표 ↗↘, 별표 ✱, `[ ]` 브래킷, 바코드풍 세로줄 — 티켓/전광판 어휘.
  (1기 브루탈 허브와 차별: 스티커·회전·그림자 금지, 이 사이트는 **플랫+직각+과밀**)

## 4. index.html — 홈 (플래그십: 키네틱 타이포)

### 플래그십 구현
1. **오프닝 전광판** — 화면을 가로 라인 4줄로 꽉 채우는 초대형 타이포:
   `SEOUL / DEV WAVE / 2026 / 10.16—17`. (Black Han Sans+Archivo 혼용, 각 줄 높이 ~22vh)
   - **스크롤 키네틱**: 스크롤 델타에 따라 홀수 줄은 왼쪽, 짝수 줄은 오른쪽으로 미세하게
     밀림(`translateX = scrollY * ±0.08`, rAF, 최대 ±6vw 클램프). 스크롤을 멈추면
     탄성 없이 그대로 정지(관성 금지 — 전광판은 기계적으로).
   - 각 줄 사이 1px 라임 라인. 마지막 줄 옆에 ✱ 마크가 스크롤 각도로 회전(scrollY*0.15deg).
2. **자막 바** — 오프닝 아래 라임 바에 행사 요약이 **타자기 출력**으로 한 번 찍힘
   (steps() 애니메이션, IO 진입 1회): "이틀 · 트랙 3개 · 세션 24 · 연사 18인 · 성수 에스팩토리".
3. **키워드 그리드** — 3px 보더 6셀(3×2): AI/웹/인프라/커리어/오픈소스/라이트닝토크.
   각 셀 hover 시 배경 블랙↔라임 즉시 반전(0.1s) + 셀 안 화살표 ↗가 45° 회전.
   **글리치 hover**: 셀 제목에 `text-shadow: 2px 0 #FF3E6C, -2px 0 #3EC6FF` 가 3프레임
   steps로 깜빡(hover 동안만, reduced-motion 제외).
4. **연사 프리뷰** — 연사 6인 얼굴이 보더 셀 그리드로. hover 시 사진이 라임 duotone
   (mix-blend + 배경 라임)으로 반전, 이름+소속 등장. speakers.html 링크.
5. **엔딩 — 티켓 스텁**: CTA 밴드 금지 → 실제 티켓 모양 컴포넌트(점선 절취선, 바코드풍
   세로줄, 좌측 행사 정보/우측 "얼리버드 진행 중" 라임 블록). 절취선 우측 전체가
   tickets.html 링크. 티켓 위 D-day 카운터(모노, 1초 갱신).

## 5. 서브페이지
- **speakers.html** — 연사 18인 중 8인 상세(나머지 10인은 "공개 예정" 실루엣 셀 —
  실제 행사 사이트 문법). 카드: 사진(1:1)+이름+소속+세션 제목+트랙 배지. 클릭 →
  `<dialog>` 프로필(약력 3줄+세션 요약+타임테이블 위치 링크).
  가상 예시: 김러너(AI 스타트업 CTO) "LLM 에이전트를 프로덕션에 넣으며 배운 것" /
  박코어(브라우저 엔지니어) "2026년의 CSS는 JS를 얼마나 대체했나" 등 — 세션명을 진짜처럼.
- **timetable.html — 두 번째 플래그십: 매트릭스 타임테이블**
  - 데스크톱: 시간(세로 10:00~18:00) × 트랙 3개(가로) CSS Grid 매트릭스.
    세션 셀 높이 = 실제 시간 길이 비례(grid-row span). 트랙별 좌측 보더 색 구분
    (라임/화이트/핑크 `#FF3E6C` — 이 페이지 한정 보조색).
  - Day1/Day2 탭 (3px 보더 탭, 활성 = 라임 채움).
  - 셀 클릭 → `<dialog>`: 세션 상세(연사·요약·난이도·자리). "내 시간표에 담기" 버튼 →
    셀에 ✱ 마크 토글(localStorage 저장 — 새로고침 유지, 저장 기능 아님을 각주로).
  - 모바일: 매트릭스 해체 → 시간순 세로 리스트(트랙 배지로 구분).
- **venue.html** — 오시는길(지도 임베드, 성수) + 층별 안내(로비/트랙A·B/트랙C/네트워킹 바 —
  텍스트 도면: 보더 셀로 구획한 평면 다이어그램) + 현장 사진 2장 + FAQ details 6개
  (주차/점심/녹화 공개/노트북 전원/커뮤니티 행동강령/환불).
- **tickets.html** — 티켓 3종 보더 셀 비교: 얼리버드 66,000(마감 D-day) / 일반 99,000 /
  학생 33,000(증빙). 포함 내역 표. [구매하기] → 외부 더미 링크. 하단에 단체(5인+) 문의 메일.

## 7. 주의사항
- 과밀은 "질서 있는 과밀"이다 — 모든 요소가 3px 보더 그리드 셀 안에. 셀 밖 떠다니는 장식 금지.
- 라임 면적을 겁내지 말 것: 페이지당 최소 한 섹션은 라임 배경 풀폭.
- 글리치·반전은 hover 한정(0.15s 이하) — 상시 깜빡임 금지(광과민성 배려, 초당 3회 이하).
- Black Han Sans는 굵기 1종뿐 — 위계는 크기와 색반전으로만.
- 키네틱 타이포는 translateX 클램프 필수(±6vw) — 과하면 텍스트가 화면 밖으로 나간다.
