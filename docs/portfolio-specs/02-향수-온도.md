# 02. 프리미엄 향수 브랜드 — "온도(溫度) ONDO"

> 제작 순서 2번. 폴더 `perfume-ondo`. `00-공통-가이드.md` 필독. 1기 금지 목록 준수.

## 1. 컨셉
- 가상의 니치 향수 브랜드 **온도(ONDO)**. 시그니처 향수 "온도 36.5" 를 파는 원페이지 중심 브랜드 사이트.
- 목적: 제품 상세·D2C 브랜드 시장(고단가) 견본. "제품 하나를 영화처럼 보여준다".
- 문법: **원페이지 시네마** — 화면이 고정된 스테이지 위에서 스크롤이 장면을 넘긴다.
- 무드: 초미니멀 럭셔리. 어두운 무대 위 유리병. 문장은 시처럼 짧게.

## 2. 디자인 토큰
```css
:root{
  --stage:  #0A0A0B;  /* 스테이지(다크 섹션) */
  --bone:   #EFEDE8;  /* 밝은 섹션/텍스트 */
  --haze:   #8A8880;  /* 보조 텍스트 */
  --ember:  #B4552D;  /* 온도의 포인트 — 잔불 오렌지브라운, 아주 절제해서 */
  --ease: cubic-bezier(.7, 0, .3, 1);  /* 느린 시네마틱 */
}
```
- 제목: **Nanum Myeongjo** 700(한글) + **Cormorant Garamond** 500(라틴 라벨 "ONDO 36.5").
- 본문: Noto Sans KR 300, 자간 +0.02em, 짧은 행.
- 밀도 극소: 한 화면에 문장 1~2개. 버튼도 보더 없는 밑줄 텍스트 링크가 기본.
- 1기 금지 목록 재확인: 그레인·글래스·마퀴·드롭캡 금지. 이 사이트의 질감은 **어둠과 빛뿐**.

## 4. index.html — 시네마 본편 (플래그십)

### 플래그십: 고정 스테이지 씬 전환
```html
<section class="cinema" style="height: 520vh">   <!-- 스크롤 트랙 -->
  <div class="cinema-stage">                      <!-- position: sticky; top:0; height:100dvh -->
    <img class="ly ly-bottle-front" src="images/ondo-bottle-front.jpg">
    <img class="ly ly-bottle-side"  src="images/ondo-bottle-side.jpg">
    <img class="ly ly-ing-1" src="images/ondo-ing-bergamot.jpg"> …  <!-- 원료 레이어들 -->
    <div class="ly ly-text scene-text-1">…</div> …
  </div>
</section>
```
- 스크롤 진행도 p(0~1)를 rAF에서 계산해 씬 5개에 배분. 모든 레이어는 opacity+transform만.
- **원료 이미지는 순흑 배경으로 생성됨** → `mix-blend-mode: screen` 으로 스테이지에 자연 합성.
  (`@supports not (mix-blend-mode: screen)` 폴백: 그냥 opacity 조절)
- 씬 구성:
  - **씬0 (0~0.15)**: 어둠 속 라틴 워드마크 "ONDO 36.5" 만 (Cormorant, letter-spacing이
    p에 따라 0.6em→0.15em 으로 조여듦) → 병 정면이 아주 느리게 페이드 인(scale 1.15→1).
  - **씬1 (0.15~0.35)**: 카피 "체온의 온도, 36.5" 한 줄 등장. 병은 미세하게 하강.
  - **씬2 (0.35~0.6) — 원료 부유**: 병 정면이 흐려지고(blur 대신 opacity .25),
    원료 레이어 3개(베르가못·무화과·샌달우드)가 각기 다른 속도·방향으로 떠오르며 교차
    (translateY 80px→-40px, 레이어별 계수 0.6/1.0/1.4 — 깊이감). 원료명이 명조 소형 캡션으로.
  - **씬3 (0.6~0.8)**: 병 측면 컷으로 크로스 디졸브 + 카피 "피부에서 완성되는 향".
  - **씬4 (0.8~1.0)**: 병이 중앙 정위치로, 엠버색 가는 라인이 병 아래 좌우로 그어지고
    "온도 36.5 — 50ml" + [노트 보기] [구매하기] 밑줄 링크 2개.
- 씬 텍스트는 실제 DOM(접근성) — reduced-motion 시 스테이지를 해체해 씬들을
  일반 세로 섹션 5개로 표시(`.cinema { height:auto }` + 레이어 정적 배치).
- 모바일: 트랙 380vh로 축소, 원료 레이어 2개만, 텍스트 크기 유지.

### 시네마 이후 (일반 스크롤 구간)
1. **온도계 바** — 밝은(bone) 섹션 전환. 가로 가는 라인 위에 "0° — 36.5° — 100°" 눈금,
   스크롤 진입 시 엠버 라인이 36.5 지점까지 차오름. 브랜드 철학 2문장.
2. **3면 프리뷰** — 병 정면/측면/탑 3컷(`ondo-bottle-top.jpg` 포함)을 여백 크게 나란히,
   hover 시 해당 컷만 밝아짐(brightness .7→1). 클릭 → collection.html.
3. **엔딩** — CTA 밴드 금지: 어둠으로 복귀, 중앙에 한 줄 "당신의 온도에서, 다시."
   + 밑줄 링크 [스토어에서 구매]. 끝.

## 5. 서브페이지
- **notes.html** — 탑/미들/베이스 노트 3단: 각 단마다 원료 매크로 이미지(스테이지 톤) +
  원료명(명조 큰) + 두 줄 설명 + 지속 시간. 페이지 하단에 향 피라미드 SVG(선으로만).
  발향 타임라인: 0분/30분/3시간/8시간 가로 스텝.
- **story.html** — 밝은 톤. 조향사(가상 "이온유") 인터뷰 문답 3개(Q는 엠버 소형, A는 명조).
  무드 이미지 2장(`ondo-mood-1/2.jpg`) 사이 여백 극대.
- **collection.html** — 컬렉션 3종: 온도 36.5 / 온도 20.0 (차가운 시트러스) / 온도 41.2 (스파이시 앰버).
  각각 병 이미지 + 노트 요약 + 가격(89,000 / 84,000 / 96,000) — 세로로 한 종씩 풀폭,
  카드 그리드 금지.
- **purchase.html** — 구매 채널: 자사 스토어(더미)/네이버 스마트스토어(더미) 2링크,
  용량·가격 표(모노 아님 — 명조 숫자), 배송·교환 안내 접이식(details), 선물 포장 안내.

## 7. 주의사항
- 이 사이트의 적은 "과잉"이다. 섹션·문장·장식을 추가하고 싶어도 참을 것. 화면당 정보 1개.
- 스테이지 스크롤 트랙에서 씬 경계가 뚝 끊기면 안 됨 — 모든 전환은 0.1p 이상 겹쳐서 디졸브.
- 엠버색은 페이지당 1~2곳만. 버튼 박스·필 배지 금지(밑줄 링크만).
- sticky 스테이지 안에서 이미지가 layout shift 없도록 전부 absolute + 중앙 기준 transform.
